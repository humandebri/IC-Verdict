# W8A16 計上命令の全額分類

対象は 120×2304×768、212,336,640 MAC の行列積 1 回。計上値 **126,402,135** を実行された命令の種類に分類した。元の Wasm は以前の実測と同じ SHA-256 `3bbb0359cd243985ccff6879ba003563cc7f7646f52b9d035deaac971c03799f`。これは計上費用の分類であり、CPU 時間や CPU の機械語命令数の割合ではない。

`local.get/set/tee` の合計は **65,940,634（52.167342%）**。以前の 50.63% は内側の積和ループに限った数字で、今回の 52.17% は出力処理や初期化等も含むカーネル全体である。

`i32x4.dot_i16x8_s` は 26,542,080 回実行され、1 回あたり 8 個の積を処理する。8 倍すると形状から計算した 212,336,640 MAC と一致する。dot と累積加算の計上コストは合わせて 53,084,160（41.996253%）。

Wasm の `local.get` は論理的な値の参照で、CPU のロード命令 1 回を意味しない。実コードではレジスタの値の利用だけで済む場合も、移動やメモリからの復元が必要になる場合もある。`local.set/tee` にも同じ区別が必要である。

## 変数操作を型で分類

| 操作 | SIMD 値 `v128` | アドレス等の `i32` | `i64` | 計 |
| --- | ---: | ---: | ---: | ---: |
| `local.get` | 54,487,296 | 3,956,545 | 6 | 58,443,847 |
| `local.set` | 3,593,208 | 32,846 | 0 | 3,626,054 |
| `local.tee` | 3,434,112 | 436,615 | 6 | 3,870,733 |

変数操作の中でも、SIMD 値の参照が 54,487,296 を占める。行列積はロードしたベクトルと累積値を何度も再利用する。そのオペランドの参照にも毎回 1 が計上される。

Rust の「8 byte ロードして符号拡張」という記述は、この Wasm では `v128.load8x8_s` という 1 命令に融合済みである。ソース上の全操作をそのまま別々に課金しているわけではなく、LLVM が生成した Wasm の表現に対して課金している。

## 264 の内訳と全実測値との一致

計測値にはカーネル本体のほかに以下が含まれる。

- `performance_counter` の API 費用：200。
- 反復前のローカル変数操作：2。
- カーネル呼び出し、引数参照、反復更新等：1 反復につき 25。
- 反復後の基本ブロック：37。

IC は基本ブロックの費用を先にまとめて引く。このため、反復後のカウンタ読み出しのあとにある差分計算等も、そのブロックの 37 に含まれる。正確な再構成式は `反復回数 × カーネル本体 + 反復回数 × 25 + 239`。

## 再現方法と解釈

元の Wasm を wabt 1.0.39 で flat WAT にし、3 関数（dispatch、16 行タイル、8 行タイル）に命令別カウンタを追加した。追加カウンタの命令は集計対象から除き、元の命令の実行回数に IC の単価を掛けた。実行には Wasmtime Python 49.0.0 を使い、`ic0` を呼ぶ経路は到達すると失敗するようにした。入力は非ゼロの量子化行列で、両形状とも 24 出力要素をスカラーの整数積和と照合した。速度測定は行っていない。

IC 単価表は `d26cd031176beec51b39fbb9e39e80a3a46a748e` を参照。未知の実行命令には仮の単価を置かず停止する。元の Wasm のハッシュと、過去の PocketIC 実測 8 条件への完全一致を検証した。型分類は Wasm の型に基づき、実 CPU のレジスタ割当や退避回数を推定したものではない。

単に変数操作の費用を全額免除すると仮定した場合は、126,402,135 → 60,461,501、約 2.09 倍の差になる。これは料金変更の推奨値ではない。全操作を dot と累積加算だけに絞る仮定でも、現在の単価のままなら約 2.38 倍であり、この費用内訳だけから 11 倍は導けない。

```sh
python tools/trace_w8a16_metering.py \
  --wasm verdict-engine.wasm --wat verdict-engine.wat \
  --work-dir /tmp/w8a16-trace \
  --measurements docs/benchmarks/w8a16-metering/run-36112530374 \
  --out docs/benchmarks/w8a16-metering/dynamic-attribution.json
```
